# 🎓 Бот доступа к платным Telegram-каналам

Бот с инлайн-кнопками для управления доступом к приватным каналам.
Админ создаёт ссылки, пользователь активирует их, бот выдаёт/продлевает/забирает доступ.

## 🚀 Установка

```bash
cd sub
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

## ⚙️ Настройка

1. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `ADMIN_IDS` — ваши ID через запятую (узнать: [@userinfobot](https://t.me/userinfobot))

2. Добавьте бота **администратором** в каждый приватный канал с правами:
   - ✅ Приглашать пользователей (`can_invite_users`)
   - ✅ Блокировать участников (`can_kick_members`)

3. Запустите бота:
```bash
python main.py
```

## 📋 Функционал

### 👤 Пользователь
- `/start` — главное меню с инлайн-кнопками
- 💎 **Мои доступы** — список каналов, сколько дней осталось
- 🗂 **Каталог** — все каналы по категориям
- ⚙️ **Настройки** — включить/выключить уведомления, изменить срок предупреждения
- Бот напоминает за N дней до конца (по умолчанию 7) и каждый день после

### 🛠 Администратор
- **Категории** — добавить/удалить категории каналов
- **Каналы** — добавить приватный канал пересылкой сообщения из него
- **Создать ссылку** — быстрая кнопка «30 дней» или вручную указать дни
- **Статистика** — количество пользователей, каналов, доступов
- **Проверить подписки** — вручную запустить проверку и кикнуть истёкших

### 🔗 Ссылки
- Одноразовые персональные ссылки вида `https://t.me/BOT?start=XXXXX`
- Только админ может создать ссылки
- После активации пользователь получает доступ к конкретному каналу

### 📩 Заявки в канал
- При входе по ссылке бот проверяет доступ
- Если доступ есть — автоматически одобряет заявку
- Если нет — отправляет админам кнопки «✅ Одобрить / ✖️ Отклонить»

### ⏰ Истечение доступа
- Каждые 30 минут бот проверяет подписки
- Истёкшие доступы — кикает из канала
- Продлённые (например, 35 дней) — не кикает, ждёт новый срок

## 📁 Структура

```
sub/

├── scheduler.py       # Проверка истечения + напоминания
├── main.py            # Точка входа
├── requirements.txt
├── .env.example
└── handlers/
    ├── __init__.py
    ├── user.py        # Пользовательские хендлеры
    ├── admin.py       # Админские хендлеры
    └── join.py        # /start token + заявки
```

## 🔄 Как это работает

1. Админ добавляет категории и каналы
2. Админ создаёт ссылку (30 дней или другое число)
3. Пользователь переходит по ссылке → активирует → получает доступ
4. Бот напоминает за N дней до конца
5. Когда дни заканчиваются — бот кикает из канала
6. Если админ выдаст ещё (35 дней) — бот не кикает, ждёт новый срок

## 📝 Примечания

- Для работы заявок (`USE_JOIN_REQUESTS=1`) бот должен быть админом канала
- Бот кикает через `ban` + `unban` (чтобы удалить, а не забанить навсегда)
- Все данные хранятся в `bot.db` (SQLite)
